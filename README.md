# TeaBoom / Верстка карточки товара

**`teaboom-layout`** — проект верстки карточки товара для интернет-магазина TeaBoom, выполненный в рамках тестового задания при отклике на позицию верстальщика / Frontend-разработчика.

**Цель проекта** — реализовать интерфейс и организовать удобный процесс разработки: обработку HTML-шаблонов, компиляцию SCSS, отслеживание изменений и production-сборку.

**Репозиторий:** [github.com/BakulinT/teaboom-layout](https://github.com/BakulinT/teaboom-layout)

## Стек

- **HTML5** — разметка страниц
- **SCSS / Sass** — организация и компиляция стилей
- **JavaScript** — клиентские скрипты
- **Nunjucks** — шаблонизация HTML
- **Gulp 5** — автоматизация задач сборки
- **Vite** — локальный сервер для разработки и перезагрузка страницы
- **Autoprefixer, clean-css, Terser, Source Maps** — обработка и подготовка ресурсов

## Что демонстрирует проект

- Организацию исходников фронтенд-проекта
- Компиляцию SCSS и автоматическую обработку CSS
- Рендеринг HTML-шаблонов через Nunjucks
- Отслеживание изменений в HTML, SCSS, JavaScript и ресурсах
- Подготовку production-сборки с минификацией CSS и JavaScript

## Запуск проекта

### Требования

- Node.js **20.19.0+ в ветке 20.x** или **22.12.0+**.
- npm

### 1. Клонировать репозиторий

```bash
git clone https://github.com/BakulinT/teaboom-layout.git
cd teaboom-layout
```

### 2. Установить зависимости

```bash
npm install
```

### 3. Запустить режим разработки

```bash
npm run dev
```

В текущей конфигурации локальный сервер доступен по адресу **http://127.0.0.8:8050**.

### Сборка проекта

Production-сборка с минификацией ресурсов:

```bash
npm run build
```

Сборка в режиме разработки без запуска сервера:

```bash
npm run build:dev
```

Результат сборки находится в директории `dist/`.

## Назначение проекта

Это фронтенд-кейс для демонстрации навыков верстки и организации сборки с минимум сторонних библиотек и модулей. Он не заявляется как готовая e-commerce-платформа с серверной частью, каталогом товаров, оплатой или интеграциями.
